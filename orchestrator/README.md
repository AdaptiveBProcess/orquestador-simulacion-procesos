# Orquestador

Pendiente (paso 8). Primero un orquestador sencillo, sin chat, que encadene los componentes con el contrato de tarea; después la capa conversacional.

Según el diagrama de arquitectura general, esta carpeta alojará: UI, manejador de archivos, chat, analytics, supervisor, agentes y subagentes, manejador de servicios y proveedor LLM, con la persistencia de estado, escenarios, trazas y métricas. Los agentes se construyen a partir de las fichas `components/*/agent/capabilities.md`.
